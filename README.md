# Rick and Morty - Explorador de personajes

Aplicación web (HTML, CSS y JavaScript puro) que consume la [Rick and Morty API](https://rickandmortyapi.com/).

## Funcionalidades
- Listado de personajes con imagen, estado y especie
- Búsqueda por nombre (con debounce)
- Filtro por estado (vivo, muerto, desconocido)
- Paginación
- Detalle del personaje en una ventana modal

## Cómo ejecutarla
No requiere instalación. Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
# luego abre http://localhost:8000
```

## Estructura
```
index.html   -> estructura de la página
styles.css   -> estilos
app.js       -> lógica y consumo de la API
```
